⚡ 논리 게이트 퍼즐

게이트를 이어 목표 진리표를 만족하는 회로를 만드세요

스테이지

조작 방법
  • 팔레트의 게이트를 보드로 끌어다 놓거나, 눌러서 바로 추가합니다.
  • 출력 점(오른쪽)을 입력 점(왼쪽)으로 끌면 전선이 연결됩니다. 한 출력에서 전선을 여러 개 뽑을 수 있습니다.
  • 이미 연결된 입력 점을 끌면 전선을 옮기거나, 빈 곳에 놓아 끊을 수 있습니다.
  • 왼쪽 입력 상자를 누르면 0과 1이 바뀝니다. 진리표의 줄을 눌러도 그 입력으로 바뀝니다.
  • 게이트나 전선을 선택한 뒤 Delete 키(또는 선택 삭제)로 지우고, 게이트를 보드 밖으로 끌어내도 지워집니다.
